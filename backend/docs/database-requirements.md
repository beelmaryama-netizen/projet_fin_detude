# SCRUM-6 - Exigences de la base de données

## Objectif
Préparer une base de données claire et structurée pour le projet DevConnect.

## Éléments à confirmer avant l'implémentation
- Identifier les données principales à enregistrer.
- Définir les tables nécessaires.
- Choisir une clé primaire pour chaque table.
- Définir les clés étrangères et les relations.
- Prévoir les contraintes importantes (champs obligatoires, unicité, types de données).

## Critères d'acceptation
- La structure des tables est documentée.
- Les relations entre les tables sont compréhensibles.
- Les clés primaires et étrangères sont identifiées.
- Le modèle peut être expliqué et validé par l'équipe avant le développement.
