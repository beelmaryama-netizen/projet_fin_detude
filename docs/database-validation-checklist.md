# SCRUM-6 - Checklist de validation

Avant de considérer la Story SCRUM-6 comme prête :

- [ ] Les tables principales sont identifiées.
- [ ] Chaque table possède une clé primaire.
- [ ] Les relations entre les tables sont définies.
- [ ] Les clés étrangères sont identifiées.
- [ ] Les champs obligatoires sont précisés.
- [ ] Les contraintes importantes sont documentées.
- [ ] L'équipe a relu et validé le schéma.
